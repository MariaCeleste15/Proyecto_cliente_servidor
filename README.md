# Aplicación Cliente-Servidor: Producción Promedio

Aplicación cliente-servidor desarrollada en Python con Sockets para la Unidad 1.

## Descripción
El cliente solicita la cantidad total de unidades producidas y el número de trabajadores. El servidor valida que el número de trabajadores sea mayor que cero, calcula la producción promedio por trabajador y devuelve el resultado.

## Instrucciones de Ejecución
1. Iniciar el servidor:
   `python servidor.py`
2. En otra terminal, ejecutar el cliente:
   `python cliente.py`
